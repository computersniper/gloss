# Gloss 2.0 Beta — introducing the GlossX research workbench

Gloss 2.0 adds a research workbench to the local AI paper reader. You can keep reading and annotating in the classic interface, then switch to GlossX when a question becomes a project.

## What's new

- Persistent agent sessions, project threads, and an inbox for approvals and completed work.
- A multi-tab workbench for papers, notes, code, and supported Office documents.
- Project workspaces with Git history, file diffs, branches, and checkpoints.
- Tools for reading your library, browsing the web, writing files, and executing code, with permission modes and approvals.
- Skills, MCP servers, commands, hooks, and research workflows.
- Mobile pairing to read and continue sessions from a phone or tablet.
- Paper organization, reading perspectives, Markdown notes, and visual explanations.

## Upgrading from Gloss 1.x

Close Gloss and back up the data directory before opening the Beta. Existing papers, notes, highlights, chats, and settings remain in the Gloss library. New installations open in the classic reader, and the top-bar switch opens GlossX.

If you used a separate GlossX preview library, choose its directory with GLOSS_DATA_DIR. When both libraries exist, Gloss opens the classic library by default. See [data locations](https://github.com/computersniper/gloss/blob/main/README.md#-data-location).

## Downloads

- Windows x64 — Gloss.exe or Gloss-windows-x64.exe.
- Windows, macOS, and Linux local web app — gloss-local-2.0.0-beta.1.tgz.
- After npm publication — npx gloss-local@next.
- The Windows portable application includes its runtime. The npm/web app needs Node.js 18+ and Python 3.11+.
